# 多源电商数据对比：C 端大促 vs B 端分销

> **一句话结论**：同样的方法放在两份数据上，得到的是两套完全不同的经营逻辑——C 端美妆靠"大促脉冲 + 头部店铺"（双十一当天是日常的 43.9 倍，35.8% 的降价商品贡献了 79.7% 的增量，TOP5 店铺占 67.4%）；B 端日化靠"持续复购 + 客户覆盖"（客户年均 7.6 单、复购率 99.8%，但 TOP20% 客户只贡献 37.6%）。**把 C 端的 KPI 套到 B 端，会得出完全错误的结论。**

## 业务问题

手里有三份互不相关的电商数据。前一份（天猫订单）已单独成报告，这份处理后两份，重点不是"各做一遍"，而是回答一个更根本的问题：

**同一套 RFM / 集中度 / 趋势分析，放在 C 端和 B 端，结论会不会打架？**

1. C 端大促的增量从哪来？是"降价"还是"流量自然增长"？
2. B 端分销的收入结构是什么样？依赖大客户还是靠覆盖广度？
3. 两类业务的可迁移结论与不可迁移结论分别是什么？

## 数据

| 数据 | 形态 | 规模 | 时间 |
|---|---|---|---|
| 双十一淘宝美妆 | 商品维度**每日快照**（10 天） | 27,598 行 / 3,196 商品 / 19 店铺 | 2016-11-05 ~ 11-14 |
| 日化批发订单 | 订单明细（每行一个商品行） | 31,452 行 / 8,215 单 / 1,084 客户 | 2019-01 ~ 09（3 月、10–12 月缺） |

## 两份数据都有坑，这是本项目的重点

| 坑 | 处理 |
|---|---|
| 美妆是**每日累计快照**，直接加总会重复计数（会把总量放大 8 倍以上） | 每个商品取最后一天快照 = 累计销量；相邻两日差值 = 当日新增 |
| 快照**首日只有累计值**，没有增量 | 首日不计入日增量，否则会把 3,202 万件历史销量当成一天卖的 |
| 快照出现销量回落（1,333 处） | 负增量按 0 处理，口径调整无法还原 |
| 日化订单日期字段**类型混杂** | `to_datetime` 强转后剔除无效日期 |
| 区域字段脏值（`西 区` 带空格、`男区`） | 去空格，异常值单独标注（占 0.006%），不静默丢弃 |
| 日化 **3 月与 10–12 月整月缺失** | 只报 1–9 月，不外推全年 |

> 两份数据颗粒度不同，**指标不可直接比大小，只能比结构**。B 端客单价 49.2 万元/单，和 C 端百元级客单没有可比性；能比的是"集中度""复购频率"这类结构指标。

## 关键发现

1. **C 端是单点脉冲**：日常日增 6.3 万件，双十一当天 276 万件（**43.9 倍**），11/12 仍有 87.8 万件（14 倍），之后回落到 1–2 万件。
2. **C 端增量几乎全靠降价**：35.8% 的商品降价（中位折扣 25%），贡献了当天 **79.7%** 的增量。按单品算：未降价增 418 件，>40% 深折增 3,581 件——折扣越深越有效，但深折商品只占 11.3%。
3. **C 端低价商品卖得多、赚得少**：<100 元商品占 26.2% 的数量、贡献 54.6% 销量，但销售额只占 22.7%；销售额最大的是 100–200 元带（28.3%）。
4. **C 端店铺头部通吃**：19 家店铺中 TOP5 占 **67.4%** 销量，相宜本草以 824.9 万件居首。
5. **B 端没有大促，但有缓慢爬坡**：采购额 1 月 3.14 亿 → 7 月 6.22 亿（**1.98 倍**），8 月起回落。
6. **B 端客户高度分散**：TOP10% 客户只贡献 21.5%、TOP20% 37.6%、TOP30% 51.3%；客户年均下单 7.6 次、复购率 99.8%。

## 结论与建议

| # | 对象 | 建议 | 依据 | 优先级 |
|---|---|---|---|---|
| 1 | C 端选品 | 用价格弹性筛出"深折仍能赚钱"的 10–15% 商品，只对它们打深折 | >40% 深折单品增量 3,581 件，是未降价商品的 8.6 倍 | P0 |
| 2 | C 端备货 | 峰值不止备 1 天货，大促后 1 天仍要留 30% 弹性 | 11/12 增量 877,795 件，为日常 14 倍 | P0 |
| 3 | C 端阵地 | 避开头部正面竞争，切 100–200 元主力带或细分功效 | TOP5 店铺占 67.4%，中价带销售额最大 | P1 |
| 4 | B 端现金 | 4–8 月是采购高峰，提前 2 个月锁定现金流与仓容 | 采购额 7 月为 1 月的 2 倍 | P0 |
| 5 | B 端覆盖 | 以"新增有效客户数 + 续单率"为核心 KPI，而非单客户 GMV | TOP20% 客户仅 37.6%，客户年均 7.6 单 | P1 |
| 6 | 方法层面 | **C 端 KPI 不可迁移到 B 端**：集中度、客单价、季节性三套口径都要重设 | 同为电商，结构指标方向完全相反 | P0 |

## 局限性

- 美妆销售额是"单价 × 累计销量"的近似，未扣优惠券、运费与退货，绝对值偏高；
- 美妆只有 10 天窗口，无法判断大促后是否透支后续需求；
- 日化缺 3 月与 10–12 月数据，全年结论不可外推；
- 两份数据来自不同年份、不同平台，只做结构对比，不做绝对规模比较。
