## 数据模型

**星型模型**：

```
日期表（1） ──→ 订单（*）
```

- **订单**：事实表，2.8 万行，含订单编号 / 金额 / 创建时间 / 付款时间 / 退款金额，并派生 `省份`、`日期`、`小时`、`已付款` 四个字段
- **日期表**：`CALENDAR()` 生成 2020 全年 365 天，含 年 / 月 / 年月 / 日 / 星期，已标记为日期表

**为什么单独建日期表**：订单表只有 2 月有数据，直接用它做时间轴会缺 2/8、2/16 两个断档日；日期表是连续的，**断档会显示为 0，肉眼可见**——这正好是分析结论的一部分。

## 核心度量值（全部用 DAX，不用计算列）

```dax
总订单数   = COUNTROWS('订单')
已付款订单 = CALCULATE([总订单数], '订单'[已付款] = "已付款")
GMV        = CALCULATE(SUM('订单'[总金额]), '订单'[已付款] = "已付款")
退款额     = CALCULATE(SUM('订单'[退款金额]), '订单'[已付款] = "已付款")
退款订单   = CALCULATE([总订单数], '订单'[退款金额] > 0)
退款率     = DIVIDE([退款订单], [已付款订单])
占全量比   = DIVIDE([总订单数], CALCULATE([总订单数], ALL('订单'[省份])))
```

**两个刻意的设计**：

1. **比率一律用度量值**，不用计算列——计算列在切片器变化时不会重算
2. **退款率加了样本量门槛**：`IF([已付款订单] >= 30, DIVIDE(...))`，避免西藏（3 单）这类小样本冲进 TOP10

## 三个关键结论（都在看板上）

1. **量**：上旬日均 251 单 → 下旬 2,439 单（9.7 倍），峰值 2/25 单日 3,416 单
2. **钱**：退款率 23.4%，退款 57.23 万元，占 GMV 的 23.1%
3. **地区**：湖北退款率 **71.9%**（57 单已付款）、新疆 **62.8%**，分别为全站 3.1 / 2.7 倍；退款率 TOP10 省份合计占 19.6% 订单，退款率 27.4%，高于全站 23.4%

## 口径说明（面试常问）

| 指标 | 定义 | 最容易错的点 |
|---|---|---|
| 成交率 | 已付款 / 创建 | 分母是**创建订单**，不是已付款 |
| 退款率 | 退款单 / **已付款单** | ❌ 不能除以总订单——那样会把 23.4% 稀释成 20% |
| GMV | 已付款订单总金额 | 未扣退款 |
| 实收 | 买家实际支付 | 已扣退款 |

**口径变更需登记版本，避免同名同义问题；断档期（2/8、2/16）不插值，仅做区间对比。**
