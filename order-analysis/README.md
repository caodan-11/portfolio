# 电商订单数据分析（3 份数据，分 3 部分）

> 三份公开数据集的**来源、字段与统计口径都不同**，因此各自独立分析、**不做跨数据集的横向对比**。
> 所有指标由 Python（Pandas）清洗计算，图表由 Matplotlib 生成，SQL 脚本见 `sql/`。

📄 **[完整报告](./电商订单数据分析报告.pdf)**（8 页）

---

## 三份数据分别是什么

| 部分 | 数据集 | 规模 | 能回答的问题 |
|---|---|---|---|
| Part 1 | 天猫订单明细 | 28,010 单 / 31 个省份 | 成交与退款整体情况、下单在时间与地域上的规律 |
| Part 2 | 双十一淘宝美妆 | 27,598 条 / 22 家店铺 / 10 天快照 | 大促期间销量怎么走、谁卖得多、谁卖得贵 |
| Part 3 | 日化批发订单 | 3.1 万单 / 1,084 个客户 / 122 个 SKU | 需求在月份、地区、品类上的分布，以及客户价值排序 |

---

## Part 1：天猫订单

**结论**

- 整体：成交率 **86.0%**、退款率 **23.4%**、GMV **247.48 万元**、实收 **190.25 万元**；
- 地区维度**没有形成有效规律**，各省差异不构成可解释的结构，因此不展开；
- 时间维度清晰：2 月上半月受新冠疫情影响订单量偏低，下旬复工后明显回升；
- 按小时看，一天有**三个下单高峰（10 点 / 15 点 / 21 点）**，其中 **21–22 点最高**——夜间是下单主力时段。

**对运营的启示**：高峰期尤其夜间应保障客服响应速度；凌晨订单量低，排班不必平均分配。

---

## Part 2：双十一淘宝美妆

**结论**

- 日销量峰值出现在 **11 月 9 日**，最高约 3,332 万、最低约 2,782 万、平均约 3,160 万；
- 累计销量前十的店铺里，第一名**相宜本草占了前十总量的 23.21%**，头部效应明显；
- 均价榜上最贵的是**娇兰，约 1,361 元**，与走量店铺拉开明显价差。

**看图方式**：把销量榜与均价榜放在一起，可以区分「靠低价走量」和「靠高客单支撑」两类店铺。

---

## Part 3：日化批发

**结论**

- 月度订购呈**单峰**：1 月最低，**7 月最高**，之后回落（数据覆盖 1–9 月）；
- 地区前五为**上海、苏州、重庆、深圳、泉州**，需求集中在华东与华南几座城市；
- 品类上**护肤品约占 85%**，其中**面膜**是需求量最大的小类；
- 用 RFM（R 20% / F 30% / M 50%）给 1,084 个批发客户打分，可排出客户价值顺序。

## 复现

**方式一：跑 Notebook（推荐）**

```bash
jupyter notebook code/订单数据分析.ipynb
```

按顺序执行即可，三个部分的分析都在里面。

**方式二：跑脚本出图和报告**

```bash
cd code
python build_charts.py     # 生成 charts/ 下 9 张图
python build_report.py     # 生成 Word 报告（再用 LibreOffice 转 PDF）
```

> 脚本里的数据路径默认指向本地目录，跑之前把 `DATA` 变量改成 `../data`。

SQL 见 [`sql/order_analysis.sql`](./sql/order_analysis.sql)，包含整体指标、时段分布、店铺排行、品类结构与客户 RFM 打分。

## 说明

- 数据全部为公开数据集，不含任何公司内部数据；
- 天猫数据没有退款原因字段，退款率只呈现规模、不做归因；
- 美妆数据为每日销售快照，反映的是当日销量，不能当作累计值使用。
